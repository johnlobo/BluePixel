Manual de BluePixel

Emulador Amstrad CPC / CPC+ para macOS, port nativo de WinAPE 2.0 beta 2, con depurador y grabación de partidas con rebobinado.

Qué es BluePixel

Emula CPC 464, 664, 6128 y las gamas Plus (con ASIC y cartuchos), con sonido AY-3-8912, discos, cintas, snapshots, Multiface 2 y ratón AMX. El núcleo está escrito en C portable y la interfaz en AppKit.

Contenido del manual

  • Línea de comandos

    Abrir discos, arrancar programas, cargar snapshots y símbolos.

  • Depurador

    Pasos, breakpoints, logpoints, watch, símbolos, raster y depuración inversa.

  • Grabar y reproducir

    Graba una partida, rebobínala como un vídeo y depúrala en cualquier instante.

Este manual crece con el emulador: cada función nueva se documenta aquí. El inventario de funciones de WinAPE que faltan por portar está en FEATURES.md.

Primeros pasos

  1. Compila y empaqueta: swift build -c release && tools/bundle.sh. Se crea build/BluePixel.app.
  2. Abre un disco con File → Drive A: → Insert Disc Image… (Ctrl+F1), arrastrándolo a la ventana, o desde la línea de comandos.
  3. Escribe RUN" y pulsa Enter, o arranca con /A para ejecutar el primer programa.
  4. Ajusta modelo, memoria, pantalla, sonido y teclado en el menú Settings (F12 abre General).

En el teclado del Mac las teclas F hacen funciones del sistema por defecto: usa fn+tecla, o activa «Usar F1, F2, etc. como teclas de función estándar» en Ajustes del Sistema → Teclado.

Estado

Funciona: emulación de CPC/CPC+, sonido, discos (lectura/escritura), cintas, snapshots, cartuchos, Multiface, AMX, auto-type, pokes, perfiles, línea de comandos, depurador completo y grabación/reproducción de sesiones con depuración inversa.

Pendiente: grabación AVI/WAV/YM, editor de discos, ensamblador integrado, Symbiface II, ZIP/RAR, impresora, joystick/gamepad, profiler. Ver FEATURES.md.
