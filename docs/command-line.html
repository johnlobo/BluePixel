Línea de comandos

MacAPE acepta las mismas opciones que WinAPE: ficheros a abrir, arranque automático de un programa, auto-type, snapshot y símbolos.

Lanzar desde el terminal

Un .app no se ejecuta directamente (da permission denied). Usa open o el script del proyecto:

tools/macape juego.dsk /A
open -a build/MacAPE.app --args juego.dsk /A

tools/macape ejecuta el binario dentro del bundle, por lo que las opciones y los mensajes de error salen en el terminal.

Opciones

OpciónEfecto
ficheroSe abre según su tipo: .dsk en la unidad A (un segundo disco, en B), .cdt/.tzx/.voc/.wav cinta, .sna snapshot, .cpr/.crt cartucho, .wpf perfil.
/AEjecuta el primer programa del disco de la unidad A.
/A:nombreEjecuta nombre. /A:|CPM arranca CP/M.
/T:ficheroEscribe el contenido de un fichero de texto de auto-type.
/SN:ficheroCarga y arranca un snapshot.
/SYM:ficheroCarga símbolos (.noi, .map, .sym, listas Maxam/WinAPE). Ver símbolos.
--type textoTeclea el texto (~ es Return).
-h, --helpMuestra la ayuda.

/T, /SN y /SYM aceptan el fichero con dos puntos (/SYM:x.noi) o como siguiente argumento (/SYM x.noi). También valen los estilos -A, --a y /a=prog. Una barra inicial solo se toma como opción si es un nombre conocido, así que las rutas absolutas siguen funcionando.

Si un fichero no existe, se avisa y se ignora; el resto de opciones se aplican.

Ejemplos

# Probar un juego de CPCtelera con sus símbolos
tools/macape obj/juego.dsk /A /SYM obj/juego.noi

# Arrancar CP/M con dos discos
tools/macape cpm.dsk datos.dsk /A:|CPM

# Cargar un snapshot
tools/macape /SN partida.sna
